# Frontend documentation

The workspace documentation home is the backend repository:

- https://gitlab.nixps.net/open-dental/core/open-dental-dashboard-backend/-/tree/main/docs

Only documentation owned by the frontend lives here. Today that is the UI-facing subset of the
Workflow Builder set:

- `workflow-builder/completion-plan.md`
- `workflow-builder/demo-runbook.md`
- `workflow-builder/piece-01-onboarding-magic-link.md`

Those three link to their sibling Workflow Builder docs, which live in the backend repository; the
links are absolute because relative links cannot cross repositories in the GitHub or GitLab web UI.

Frontend-specific task notes are kept under `full-version/odd-tasks/`.
